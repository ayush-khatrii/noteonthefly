# Note on the Go

A clean, dark-mode note editor with secure passcode access and encrypted notes.

Built with Next.js, Tailwind CSS, TipTap, shadcn/ui, and Supabase.

- Open or create a workspace using a passcode
- Secure sessions stored in an HTTP-only cookie
- AES-256-GCM encryption for note content
- Fullscreen rich-text editor with slash commands and formatting tools
- Slide-out menu for syncing, locking, formatting, and disconnecting
- Notes save automatically after you stop typing
- Works locally if Supabase is not configured
